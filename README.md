# Student Education Embedded System EDA

## Overview

This project analyzes student education and embedded systems data to identify patterns and insights related to student performance and success.

## Tools Used

- Excel
- Python
- Power BI

## Project Process

- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Data visualization
- Dashboard creation
- Analysis of student performance and success

## Files

- `data/` – Dataset used for the analysis
- `excel/` – Excel analysis
- `python/` – Python analysis and EDA
- `powerbi/` – Power BI dashboard

## Key Areas Analyzed

- GPA
- Course completion
- Quiz performance
- Projects
- Innovation
- Startups
- Funding
- Industry collaboration
- Internship status
- Student success

## Conclusion

The project demonstrates an end-to-end data analysis process using Excel, Python, and Power BI to explore student education and embedded systems data.
